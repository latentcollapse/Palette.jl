New task, in the same repository: json5/ contains the JSON5Lite Julia package, which is only a stub. Implement JSON5Lite.parse(text) for the full JSON5 specification (https://spec.json5.org): comments, trailing commas, single-quoted strings, unquoted identifier keys (including $ and _), hexadecimal numbers, leading or trailing decimal points, explicit plus signs, Infinity, -Infinity and NaN, escaped line breaks in strings, and all JSON5 string escapes. Objects become Dict{String,Any}, arrays Vector{Any}, null becomes nothing, integers without a fraction or exponent become Int, and other numbers Float64. Invalid input must throw JSON5Lite.ParseError, which reports the line and column. Add thorough tests, run them with julia --project=json5 json5/test/runtests.jl, and say when the task is complete.
