New task, in the same repository: toml/ contains the TOMLLite Julia package, which is only a stub. Implement TOMLLite.parse(text) for TOML v1.0 without date and time values (you may reject them): bare, quoted and dotted keys; basic and literal strings, including multi-line forms and all escapes; integers in decimal, hex, octal and binary with underscores; floats including exponents, inf and nan; booleans; arrays; inline tables; standard tables; and arrays of tables. Tables become Dict{String,Any} and arrays Vector{Any}. Do not use Julia's TOML standard library. Invalid documents, including redefined keys or tables, must throw TOMLLite.ParseError with the line number. Add thorough tests, run them with julia --project=toml toml/test/runtests.jl, and say when the task is complete.
